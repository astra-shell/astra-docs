Configuration File

Astra uses a TOML configuration file: 

~/.astrarc

General Settings

[general]

theme = "crimson"
startup_message = true
update_check = false
telemetry = false

Prompt Settings

[prompt]

show_user = true
show_hostname = true
show_directory = true
show_git = true
show_time = true
symbol = "❯"

History

[history]

enabled = true
file = "~/.astra_history"
size = 10000

Aliases

Aliases allow shortcuts for commands. 

[aliases]

ll = "ls -la"
gs = "git status"

Appearance

[appearance]

unicode = true
nerd_fonts = true
animations = true
compact = false
