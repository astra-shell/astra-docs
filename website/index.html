Welcome to Astra

Astra is a modern shell built in Rust. It focuses on speed, customization, and a clean developer experience.

Features

  • Rust-based shell engine
  • Custom prompt themes
  • Git integration
  • Configurable aliases
  • Command completion
  • Plugin support

Quick Start

git clone https://github.com/SYOP200/astra-shell
cd astra-shell
cargo build --release
./target/release/astra
